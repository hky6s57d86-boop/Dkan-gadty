# تراث جدّتي — موقع الكتالوج

موقع بورتفوليو وكتالوج منتجات عربي (RTL) لعرض منتجات شعبية وتراثية، هدفه الأساسي توجيه الزوار للتواصل والطلب عبر واتساب. لا يحتوي على سلة مشتريات أو دفع إلكتروني أو تسجيل دخول.

---

## 1. أين أغيّر اسم المتجر ورقم الواتساب والمدينة

كل هذه البيانات في مكان واحد فقط:

```
js/config.js
```

افتحي الملف وعدّلي القيم التالية:

```js
storeName: "تراث جدّتي",        // اسم المتجر
whatsappNumber: "9665XXXXXXXX", // رقم الواتساب الدولي بدون + وبدون مسافات
city: "المملكة العربية السعودية",
```

**مهم بخصوص رقم الواتساب:** اكتبيه بالصيغة الدولية بدون "+" وبدون مسافات، مثال لرقم سعودي يبدأ بـ 05:
- الرقم المحلي: 0512345678
- الصيغة المطلوبة: 966512345678

في نفس الملف يمكنك أيضًا تعديل:
- `aboutText` → نص قسم "عن المتجر"
- `generalWhatsappMessage` → رسالة زر التواصل العام
- `productWhatsappMessageTemplate` → رسالة الاستفسار عن منتج معيّن (استخدمي `{product}` كمكان اسم المنتج)
- `footerNote` → نص حقوق الموقع في التذييل

---

## 2. كيف أضيف صور المنتجات

1. ضعي صورة المنتج داخل مجلد:
   ```
   assets/products/
   ```
2. افتحي ملف `js/products.js` وابحثي عن المنتج المطلوب.
3. عدّلي حقل `image` ليشير إلى مسار الصورة، مثال:
   ```js
   image: "assets/products/thobe-banat-1.jpg",
   ```

إذا تركتِ `image: ""` سيظهر بديل أنيق تلقائيًا (أيقونة + عبارة "صورة المنتج قريبًا") بدلاً من صورة وهمية، وذلك حتى لا يظهر أي منتج بصورة غير حقيقية.

**نصيحة:** استخدمي صورًا مربعة الأبعاد تقريبًا (مثل 800×800) لأفضل شكل داخل بطاقات المنتجات.

---

## 3. كيف أضيف منتجًا جديدًا أو أحذفه

كل المنتجات موجودة في ملف:

```
js/products.js
```

### لإضافة منتج جديد
انسخي أحد العناصر الموجودة داخل القائمة `PRODUCTS` وعدّلي بياناته:

```js
{
  id: "other-3",                 // رمز فريد لا يتكرر مع أي منتج آخر
  name: "اسم المنتج",
  category: "other",             // انظري قائمة التصنيفات بالأسفل
  description: "وصف مختصر اختياري",
  price: 60,                     // رقم، أو null إن كان "السعر عند الطلب"
  image: "assets/products/my-product.jpg", // أو "" إن لم تتوفر الصورة بعد
  available: true,               // false إذا كان غير متوفر حاليًا
},
```

### لحذف منتج
احذفي العنصر بالكامل (من `{` إلى `}` متضمنًا الفاصلة) من قائمة `PRODUCTS`.

### التصنيفات المتاحة (استخدمي المفتاح الإنجليزي فقط في `category`)

| المفتاح    | يظهر في الموقع باسم |
|------------|------------------------|
| `kids`     | ملابس الأطفال          |
| `women`    | الملابس النسائية        |
| `burqa`    | البراقع                |
| `henna`    | الحناء                  |
| `bukhoor`  | الدخون والبخور          |
| `prayer`   | جلال الصلاة             |
| `other`    | منتجات أخرى             |

---

## 4. كيف أغيّر السعر أو التصنيف لمنتج موجود

في نفس ملف `js/products.js`، ابحثي عن المنتج بالاسم أو `id`، ثم عدّلي:
- `price` لتغيير السعر (أو اجعليه `null` لعرض "السعر عند الطلب")
- `category` لتغيير التصنيف (استخدمي أحد المفاتيح في الجدول أعلاه فقط)

---

## 5. كيف أشغّل الموقع محليًا على جهازي

الموقع HTML/CSS/JS بسيط ولا يحتاج تثبيت أي برنامج، لكن لأفضل تجربة (خصوصًا حتى تعمل الصور بشكل صحيح) يُفضّل تشغيله عبر خادم محلي بسيط:

**الطريقة الأسهل:**
افتحي ملف `index.html` مباشرة في المتصفح (دبل كليك عليه).

**الطريقة الموصى بها (باستخدام Python):**
```bash
cd اسم-المجلد
python3 -m http.server 8080
```
ثم افتحي المتصفح على: `http://localhost:8080`

**أو باستخدام إضافة VS Code:**
ثبّتي إضافة "Live Server" ثم اضغطي "Go Live" وأنتِ داخل الملف `index.html`.

---

## 6. كيف أنشره على GitHub Pages أو Vercel

### النشر على GitHub Pages
1. أنشئي مستودع (Repository) جديد على GitHub وارفعي إليه جميع ملفات المشروع.
2. من إعدادات المستودع Settings → Pages.
3. اختاري Branch: `main` والمجلد `/root`، ثم احفظي.
4. سيصبح الموقع متاحًا خلال دقائق على رابط مشابه لـ:
   `https://اسم-المستخدم.github.io/اسم-المستودع/`

### النشر على Vercel
1. أنشئي حسابًا على [vercel.com](https://vercel.com) وسجّلي الدخول عبر GitHub.
2. اضغطي "Add New Project" واختاري مستودع الموقع.
3. اتركي إعدادات البناء فارغة (الموقع HTML ثابت ولا يحتاج أي أمر بناء).
4. اضغطي Deploy، وسيعطيكِ Vercel رابطًا مباشرًا للموقع.

## 7. هيكل الملفات

```
├── index.html              الصفحة الرئيسية (كل الأقسام)
├── css/
│   └── style.css           التصميم الكامل للموقع
├── js/
│   ├── config.js           بيانات المتجر ورقم الواتساب (عدّلي هنا)
│   ├── products.js         قائمة المنتجات (عدّلي هنا)
│   └── main.js              الكود البرمجي للفلاتر، نافذة الصور، القائمة، واتساب
├── assets/
│   ├── products/            ضعي صور المنتجات هنا
│   └── icons/                أيقونة الموقع (favicon)
└── README.md                 هذا الملف
```

---

## ملاحظات مهمة

- الموقع لا يحتوي على قاعدة بيانات أو خادم خلفي (Backend)، وكل التعديلات تتم عبر ملفي `config.js` و`products.js` فقط.
- لا تعتمد أي صورة في الموقع على روابط خارجية؛ الصور تُقرأ من داخل مجلد `assets/products` فقط.
- الموقع مُختبر ويعمل بدون أخطاء برمجية على مقاسات الجوال (375px)، الأجهزة اللوحية (768px)، وشاشات الكمبيوتر (1440px).
